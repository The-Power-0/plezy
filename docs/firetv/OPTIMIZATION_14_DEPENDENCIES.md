Stage 14 — conservative asset and dependency pruning. Flutter asset declarations for Jellyfin branding and Trakt, MAL, AniList and Simkl logos are removed in the Plex-only, no-external-services candidate. Their original source files remain in upstream source archival for license transparency; removed declarations exclude them from the compiled asset bundle. Discord IPC was already removed in Stage 02. Do NOT remove `openwatchparty` at this stage: disabled Watch Together code still imports shared types and removal without refactoring would break compilation. Likewise keep `mpvAarNatives` only as a checksum-pinned FFmpeg audio library build input; actual MPV runtime is excluded. Do not remove codecs, libass, required fonts, DRM libraries or Fire TV URL entrypoints. A full dependency graph and license scan remain mandatory before production.
